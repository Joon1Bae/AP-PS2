# 1a. Do we have Complete Markets in this economy?

Yes.

**Definition (Complete Markets).** Markets are complete if there is one contingent claim
(Arrow-Debreu security) for each state of nature n = 1, ..., N, where the contingent claim for
state n pays $1 if state n materializes and $0 otherwise (Module 2, slide 1.3).

Let's define the payoff matrix X = [10, 20, 30; 10, 10, 10; 0, 10, 10]
(rows: assets A, B, C; columns: states n = 1, 2, 3).
Then, there exists \Omega s.t. X'\Omega = I, \Omega = X'^{-1} if X' is invertible.

Even if a contingent claim is not traded directly, it exists in this economy if a portfolio of
the traded assets A, B, and C replicates it, i.e., pays $1 in state n and $0 otherwise.
\Omega tells us how many units of each asset to hold to replicate the contingent claims
(column n of \Omega is the replicating portfolio for the contingent claim of state n).
Since X'\Omega = I, if X' is invertible, then a replicating portfolio for each contingent claim
exists in this economy.

Therefore, Checking whether X' is invertible or not is sufficient for Complete market in this economy.
Since det(X') = 1000 ≠ 0, X' is invertible. Therefore, this market is complete.

X^{-1} = [0, 0.1, -0.1; -0.1, 0.1, 0.2; 0.1, -0.1, -0.1] (det(X) = 1000).
